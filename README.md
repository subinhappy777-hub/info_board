# T04-1. 오늘의 진짜 관광정보판 — 데이터가 안 올 때

한국관광공사 국문 관광정보 서비스 Open API를 활용하여 축제 정보를 수집하고, API 장애나 데이터 지연 상황에서도 **마지막 정상 데이터를 안전하게 보존(Fail-Safe)**하여 사용자에게 신뢰할 수 있는 정보를 제공하는 대시보드 웹 애플리케이션입니다.

---

## 📌 7. 제출물 필수 기재 사항

### ③ 짧은 확인 방법 4줄
1. **위치**: 공개 웹페이지(`https://subinhappy777-hub.github.io/info_board/`)로 접속합니다.
2. **행동**: 상단의 [대한민국 지역별 축제 지도]에서 충청도/전북/전남 등 원하는 권역을 클릭하고, 마음에 드는 축제 카드를 누릅니다.
3. **통과 모습**: 해당 지역만의 추천 축제가 필터링되어 나타나며, 카드를 클릭하면 개막까지 남은 D-Day 카운트다운과 상세 일정, 장소 지도 정보 모달이 열립니다. (상단 오류 5종 테스트 클릭 시에도 Fail-Safe로 정상 보존 확인 가능)
4. **안 될 때 모습**: 지역 선택 시 목록이 백지가 되거나, 축제 카드 클릭 시 상세 정보가 뜨지 않고 빈 화면이 노출됩니다.

### ④ AI와 나의 판단 3줄
1. **AI에게 맡긴 일**: 한국관광공사 API 호출 및 정제 스크립트 작성, SVG 인터랙티브 대한민국 권역 지도 및 상세 모달 UI, 기간 필터 및 5종 오류 모의 시뮬레이션 인터페이스 코드 구현.
2. **직접 판단한 일**: 공공데이터포털 축제 API(searchFestival2) 선정, 단순 D-day 경과와 실제 축제 정보 수정의 구분 기준 수립, 사용자가 전국 권역(충청/전북/전남 등)별로 축제를 직관적으로 탐색하고 세부 정보를 한눈에 파악할 수 있는 지도 중심 인터랙션 구조 결정.
3. **AI 제안을 따르지 않은 일**: AI가 제안했던 빠른 테스트용 임의 mock/샘플 데이터 주입 방식을 배제하고, 지시사항에 따라 반드시 실제 공공데이터 API를 직접 호출한 실제 일자별 이력만 history에 누적되도록 엄격히 통제함.

## 🚀 핵심 구현 기능

1. **실제 관광정보 수집 및 보존 (`collector/collect.py`)**:
   - 한국관광공사 `searchFestival2` API로부터 최신 축제 정보 수집
   - 응답 검증(Status 200, header resultCode '0000', 필수 필드 존재 여부) 통과 시에만 `latest.json` 안전 갱신
   - API 요청 실패 시 기존 `latest.json`을 절대 덮어쓰지 않고 `events.json`에만 장애 원인 기록
2. **지능형 Diff 엔진 (어제 vs 오늘 데이터 비교)**:
   - 신규 등록된 축제 (New)
   - 정보가 수정된 축제 (Modified Time, 명칭, 장소 변경 등)
   - 종료되거나 목록에서 제외된 축제 (Ended/Removed)
   - **D-Day 변화 분리**: 날짜 경과에 따른 단순 D-Day 변화는 실제 정보 수정과 명확히 구분하여 표기
3. **5종 장애 상황 시뮬레이터 (Fail-Safe 검증)**:
   - ⏱️ `Timeout`: 응답 10초 초과 지연 모의
   - 🔑 `인증 오류`: 401/403 잘못된 키 응답 모의
   - 🛑 `호출 제한`: 429 일일 트래픽 초과 모의
   - 🔌 `네트워크 오류`: 인터넷 단절 모의
   - ⚠️ `데이터 오류`: JSON 파싱 에러 및 필수 필드 누락 모의
   - *모든 오류 상황에서 화면의 축제 데이터가 보존됨을 실시간 콘솔 및 배너로 확인 가능*

## 🛠️ 실행 및 테스트 방법

### 1. 데이터 수집기 실행
```bash
# .env 파일에 TOUR_API_KEY 등록 후 실행
python collector/collect.py
```

### 2. 웹 대시보드 열기
`public/index.html` 파일을 웹 브라우저로 열거나, 로컬 웹 서버(Live Server 또는 Python HTTP 서버)로 실행합니다:
```bash
cd public
python -m http.server 8000
# 웹 브라우저에서 http://localhost:8000 접속
```
